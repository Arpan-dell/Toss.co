# Phase 2: the headless basket

Screen recordings from Phase 2, when the basket lost its display and moved all control to the phone.

| File | What it shows |
|---|---|
| `phase-2-demo.mp4` | The 27-second narrated summary (square, made for LinkedIn) |
| `telegram-bot-control.mp4` | The customer bot (SmartLaundry Control): tare, live weight, Wi-Fi status, adding a network by message, a manual order reaching the driver bot (Laundry_Bot), setting the pickup address |
| `wifi-setup-captive-portal.mp4` | Joining an unknown network: the basket's `Smart_Laundry_Setup` hotspot, the WiFiManager captive page, picking a network and entering the password |

Passwords, the home Wi-Fi name, the saved pickup address and the Telegram chat list are blurred in every frame.
